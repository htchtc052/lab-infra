# Timeweb: пауза, возврат

Деплой — в `DEPLOY.md`. Здесь только то, что специфично для этого хостинга.
`<VPS_HOST>` ниже — текущий публичный адрес сервера, тот же, что хранится в
GitHub Secret `VPS_HOST`; это не постоянный адрес проекта.

## Пауза — 240 ₽ вместо 1200 ₽

Способ остановить расходы, сохранив всю настройку. Работает только при
**положительном балансе**: при нулевом всё удаляется, см. ниже.

**1. Остановить стек.** Иначе база попадёт в снимок посреди записи.

```bash
ssh root@<VPS_HOST> 'cd /srv/lab/infra && docker compose stop'
```

**2. Снять образ.** Сервер → Образы → создать. Диск занят около 10 ГБ, хранение
4 ₽/ГБ в месяц.

**3. Удалить сервер.** Почасовые списания прекращаются.

**4. Адрес не удалять.** Публичный IP закреплён за аккаунтом, а не за сервером,
и переживает его удаление. Он тарифицируется и без привязки — 200 ₽ в месяц, и
это плата за то, что при возврате не придётся трогать DNS.

**5. Оставить деньги на балансе** — на образ и адрес, с запасом на весь срок
паузы. Это единственное, что отделяет паузу от потери всего.

## Возврат

Создать сервер из образа (Образы → создать сервер), привязать **тот же** IP.

```bash
ssh root@<VPS_HOST> 'cd /srv/lab/infra && docker compose up -d'
```

DNS менять не нужно — привязан к адресу, который сохранился.

## Неуплата — не пауза

При нулевом балансе аккаунт блокируется, и через **7 дней автоматически
удаляются серверы, облачные сервисы и все связанные данные, включая образы**.
Публичные IP относятся к тем же связанным ресурсам — просто перестать платить
значит потерять и снимок, и адрес. Уцелеют только репозитории на GitHub, и
разворачивать придётся с нуля на новом IP (см. `DEPLOY.md`).

## Что переживает всё

Домен и его DNS-зона. Поддержка подтвердила: домены, зарегистрированные через
Timeweb, при блокировке аккаунта не снимаются с делегирования, файл зоны
остаётся без изменений — записи уцелеют, но будут указывать на
несуществующий адрес, пока не поднят новый сервер.

## Если адрес потерян

Новый сервер — новый IP. Поправить DNS → A для `photo`, `photo-api`, `mail`, и
SPF (TXT на корне, содержит адрес числом), и PTR в Сеть → Публичные IP.
DKIM-ключ живёт в томе `postfix_dkim` и с образом сохраняется; потеряется —
`boky/postfix` перегенерирует сам, просто письма перестанут проходить DKIM,
пока не обновишь TXT `mail._domainkey`. Почта тут не критична (только
password-reset) — можно почитать `docker compose logs postfix`, когда
дойдут руки, это не блокирует остальное.

## Прочее по этому хостингу

- Порты 25, 465, 587, 2525 закрыты по умолчанию; разблокируются через поддержку.
- Docker Hub отдаёт `429` анонимным клиентам. В `/etc/docker/daemon.json`
  прописано зеркало `https://dockerhub.timeweb.cloud`.
